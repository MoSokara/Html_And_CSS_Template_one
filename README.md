# Sokara | HTML & CSS Template One

A simple and clean personal portfolio template built with **HTML** and **CSS** only.  
This project is designed to showcase my skills, services, and portfolio work in a minimal and modern style.

Live Demo:  
🔗 **https://mosokara.github.io/Html_And_CSS_Template_one/**

---

## 🚀 Features

- Fully responsive design  
- Clean and simple layout  
- Fast loading performance  
- Easy to customize  
- Works on all modern browsers  
- Smooth and minimal user experience

## 📦 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/MoSokara/Html_And_CSS_Template_one.git
   ```

2. Open the project folder.

3. Run the website by opening:
   ```
   index.html
   ```

No build tools required.

---

## 🌐 Deployment (GitHub Pages)

The project is hosted using **GitHub Pages**.

To deploy:

1. Go to your repo **Settings**  
2. Click **Pages**  
3. Choose `main` branch  
4. Select root `/`  
5. Save

Your live website will appear at:

```
https://username.github.io/repository-name/
```
